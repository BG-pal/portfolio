STEP 01 DISCOVER

“Understand before designing.”

Every interface starts with empathy and active listening. Before opening Figma or sketching layouts, I immerse myself in user contexts and business constraints.

  • • Understand the core problem.
  • • Understand users & stakeholders.
  • • Gather functional requirements.
  • • Explore context and constraints.
USER → NEED → PROBLEM
PAGE 01
STEP 02 DEFINE

“Turn observations into direction.”

Synthesizing qualitative feedback into a concrete North Star prevents scope creep and aligns cross-functional engineering and product partners.

  • • Identify specific user needs.
  • • Map acute pain points.
  • • Clarify core product goals.
  • • Define constraints and boundaries.
PROBLEM → GOAL → DIRECTION
PAGE 02
STEP 03 IDEATE

“Explore possibilities before choosing a direction.”

Rapid low-fidelity sketches and decision trees allow testing hypotheses fast without getting attached to visual styling too early.

  • • Explore comprehensive user flows.
  • • Structure information architecture.
  • • Compare alternative approaches.
  • • Evaluate density vs speed trade-offs.
FLOW → OPTIONS → SOLUTION
PAGE 03
STEP 04 DESIGN

“Turn structure into experience.”

Applying typography, 8pt spacing rhythm, tokenized color palettes, and accessible component libraries to bring products to life.

  • • Reconstructed Wireframes.
  • • High-fidelity responsive UI.
  • • Scalable design systems.
  • • Interactive prototypes.
Component State: Active UI
PAGE 04
STEP 05 VALIDATE

“Learn, refine and improve.”

Validating design decisions against real-world edge cases and stakeholder reviews to ensure accessibility and developer feasibility.

  • • Review design decisions.
  • • Gather stakeholder feedback.
  • • Identify usability friction.
  • • Refine the final experience.
DESIGN → FEEDBACK → ITERATE
PAGE 05
STEP 06 IMPROVE

“Good design evolves.”

“I believe design is an ongoing process of understanding, testing and improving the experience.”

UNDERSTAND → DEFINE → IDEATE → DESIGN → VALIDATE → IMPROVE
